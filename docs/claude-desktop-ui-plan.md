# Cage 对照 Claude Desktop 的改版方案

参考日期为 2026-11-12。目标是在 Windows 上把 Cage 自己绘制的界面做到与本机 Claude Desktop 同样的排版、密度、文字习惯和操作反馈。首轮以简体中文交付，英文用于核对原版操作语义。工作起点为 `feat/workbench-redesign` 的当前工作树。

## 参考依据与取值方法

| 来源 | 已核实 | 实施时怎么用 |
| --- | --- | --- |
| 本机 Windows Claude Desktop 5.1231.2，真实首页的辅助功能树 | 当前页面为 New chat。侧栏有 Chat and Cowork / Code 两个模式，含 New、Search、Projects 等入口，可折叠、可拖宽。当前宽度控件返回 244。当前客户端呈现英文。 | 首先用这一版固定首页、模式切换和侧栏结构。244 是这台机器当前控件的读数，默认值和单位需在同 DPI 截图中复核。 |
| 同版主窗口与共享框架样式 | 包内包含品牌陶土色 `#D97757`、明暗表面、Anthropic Sans / Serif / Sans Micro 字体族。共享框架中有 288px 的侧栏变量、13/14px 行文字、12/13px 分组字、16/20px 图标、8px 卡片圆角及独立浮层阴影。不同选择器和窗口使用不同值。 | 提取角色及测量结果，按真实页面逐处匹配。尤其不能把 288px 或 8px 当成所有页面通用值。字体打包前确认可分发来源；缺字按同一段中文逐行校准回退字体、宽度和基线。 |
| 桌面壳简中语言资源 | 可核对“新建对话”“新建会话”“设置…”“关闭窗口”等。同一份资源覆盖多种场景。 | 将每个词关联实际控件。网页内容、Claude Code 会话与系统菜单各自取样，不能用壳内词表推断整套简中界面。 |
| 官方产品说明 | 官方说明有浅色、深色、跟随系统和聊天字体选项，聊天与 Cowork 界面存在分批更新。 | 跨版本有冲突时，用约定的本机窗口和场景记下差异。[外观说明](https://support.claude.com/en/articles/8887527-customizing-your-appearance-settings) · [体验版本说明](https://support.claude.com/en/articles/15520349-use-claude-cowork-on-web-desktop-and-mobile) |

## 文字、样式和效果的实施规格

1. **先做全量文案清单。** 当前 `ui/src` 的非测试 JS/JSX/MJS 中有 87 个文件、2,155 行含中文，是定位量，包含注释与重复引用。扫描 JSX 文本、字符串分支、插值、placeholder、title、aria-label、原生菜单和 Go 返回的可见状态，再按实际显示位置去重。清单每条记录场景、控件、现文案、原版同义词或 Cage 拟稿、变量、复核状态。每个可见控件都能追溯到清单，共用“取消”“设置”等短词，保留每个操作自己的无障碍名称。
2. **逐条对动作。** “新建对话”仅用于创建可发送的对话，“新建终端”继续表示启动 PTY；首页“先启动 Cage 环境”可试为标题“启动工作环境”和按钮“启动环境”。同一动作统一菜单、按钮、快捷键提示；程序菜单里的“设置…”与页面标题“设置”分开。覆盖标点、省略号、数字单位、快捷键、中文与英文产品名混排、长路径、校验错误、加载中与空状态。上述首页措辞是 Cage 拟稿，需在样板对照中定稿。
3. **把样式参数落到一处。** 在现有预设中增加独立的 Claude Desktop 预设；[前端默认值](../ui/src/appearance-state.mjs)与 [Go 默认值](../internal/workbench/appearance.go)同步。为底层画布、侧栏、浮层、输入区、正文、次要文字、焦点、选中态分别定义明暗值。按控件角色设置字族、字重、行高、图标尺寸与笔画、行内边距、圆角、边线及阴影。新安装可默认启用；已有显式预设、自定义颜色和导入主题保留选择。首帧 CSS、系统高对比和原生背景同步验证。
4. **效果按状态逐个还原。** 对侧栏折叠、菜单展开、弹窗、tooltip、行尾操作、输入框增长、生成中/停止、标签拖动与分屏记录触发条件、延迟、持续时间、位移、曲线、关闭及中途反转。用同帧率录屏逐帧比较。静态按钮也覆盖悬停、按下、键盘焦点、选中及禁用。遵循系统或用户的减弱动态设置；后台窗口、隐藏终端和远程画面延续现有节流与挂载策略。

## 顺序与验收

| 阶段 | 可验收交付 | 通过条件 |
| --- | --- | --- |
| 1. 冻结参照 | 同版 Windows 对照图与短录屏、文字清单、字体与样式参数表 | 覆盖首页空态、长侧栏、菜单、已发送会话、设置、弹窗，浅深各一份。记录 100% 与 125% DPI。凡缺少参照的条目明确标为待取样。 |
| 2. 第一版 Windows 样板 | 原生窗口中可操作的首页、展开与折叠侧栏、输入区、设置外观、菜单和确认框 | 同尺寸并排与半透明叠图检查。建议门槛为主要边缘误差 ≤2 CSS px，同条件中文样句断行和省略位置一致；菜单与侧栏动画建议起止误差 ≤2 帧（60 fps）。抗锯齿、动态光标和会话内容单独遮罩。你可在这个阶段定字体回退、侧栏密度和首页布局。 |
| 3. 铺满 Cage 功能 | 按页面表逐项迁移，补齐所有状态及原生提示，交付可测试的登录、启动、使用、恢复全流程 | 文案清单每条有去向，交互状态均有对照图或用例。中文输入法回车、Tab 导航、Esc、键盘快捷键、终端复制粘贴、分屏与重连逐项通过。 |
| 4. 性能与多端回归 | Windows 原生验收包、手机和其他桌面壳验收记录、官网文档对照 | 复跑 UI 测试及生产构建，运行主题、分屏、隐藏远程画面及手机会话冒烟。同机同数据重复冷启动与首次打开会话/终端/设置，分别记录中位数与加载字节；沿用现有按需加载。与当前验收版基线对照，任何可重复的退化须有原因和处置记录。 |

第一份值得试用的交付是阶段 2 的 Windows 原生样板。它能直接暴露字体替代、中文分行、窗口密度和菜单手感的差异，再据此铺开其他页面。
