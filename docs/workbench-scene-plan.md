# 工作台场景样式统一计划与验收

本轮从维护分支 `feat/workbench-redesign` 的 `7542935` 开始。目标是让用户从 SSH 主机管理、账户登录一路进入安装和工作台时，能凭相同的布局找到输入、主要操作、错误和详情。

| 顺序 | 实施范围 | 验收条件 |
| --- | --- | --- |
| 1 | 清点工作台实际渲染入口，包括独立于设置页的侧栏、模态窗、全屏授权页和首次启动页。统一主题表面、文本、边线、控件高度、焦点、内外边距与操作区。 | 同一层级使用一致的样式。文字可折行，窄窗可滚动到主要操作，放大字号后仍可操作。 |
| 2 | 检查 SSH 添加与编辑、认证与指纹确认、连接与重试、启动、切换、停止和移除。 | 从主机入口执行各流程，核对操作顺序、错误反馈、键盘返回和不同长度的主机信息。 |
| 3 | 检查账户创建、登录、锁定与解锁，初始化选择目录及系统、安装进度、失败重试、就绪、环境启动及客机登录。 | 主次操作和表单标签位置一致，长路径、错误与安装阻断原因可读；原有认证与启动行为通过回归。 |
| 4 | 将初始化、工作台与虚拟 Mac 设置中的操作详情接入统一的 Linux 终端输出视图。 | 原始行、缩进与空行保真；打开即进入单层终端窗口；实时追加、查看较早输出、长行、复制、空日志和错误日志均单独验证。 |
| 5 | 把首页对话输入框上方问候语前的字符星号替换为 Claude 官方图形资源。 | 明暗主题、长账户名和大字号下对齐，离线可用，拖动时问候语与图标不可选中，输入的消息和输出日志可正常选取。 |
| 6 | 检查文本输入框及密码显隐按钮的默认、聚焦、禁用和高对比度状态。 | 输入控件只绘制一圈边框，显示密码后焦点稳定；Tab、Shift+Tab、Enter 和空格能按预期操作。 |
| 7 | 在宽窗、窄窗与大字号下运行真实组件及交互检查，执行前端构建、单测和 Windows 桌面验收。 | 记录检查覆盖和实测边界，保留代表截图，交付能重新打开的验收窗口。 |
| 8 | 以本机 Windows 版 Claude Desktop 5.1231.2 的浅色与深色实测样式校准主题。普通输入框使用 6px 圆角、内描边及蓝色焦点。对话输入框使用 12px 圆角，聚焦时加深阴影。 | 对照默认、悬停、聚焦和禁用态。其他主题使用自己的底色、边线和焦点色。切换主题、已有设置和强制颜色分别验证。 |
| 9 | 核对整个用户界面的标题、按钮、字段、状态、错误和辅助说明，包括移动端、桌面原生文件窗口，以及显示给用户的后端反馈。 | 删除与标题或按钮重复的引导。报错指出下一步，保留主机指纹、权限、凭据、文件范围和不可逆操作的后果。 |

验收使用隔离配置和测试主机数据。涉及操作系统登录或 SSH 服务的步骤用可控响应复现成功与失败状态，同时检查实际组件发出的操作。

问候语图形采用 Claude 官方网站发布的 [SVG 图标](https://claude.com/icon.svg)，随桌面资源打包。图形保留官方填充和路径，装饰性图片使用空替代文本。

## 验收记录

| 场景 | 已验证 |
| --- | --- |
| 输入与主题 | 在 Windows 同一浏览器内核中对照本机 Claude Desktop 5.1231.2 安装包的样式表与工作台实际控件。浅色、深色共 22 项逐一比对底色、可见阴影、圆角及透明度。Solarized 和自定义主题另测 44 项，注册、密码和搜索框另测 30 项。 |
| 账户与密码 | 在 Microsoft Edge 验证 36 组账户密码交互，包括强制颜色、放大字号、空值和输入后的 Tab 顺序、点击保留选区。浏览器原生显隐按钮被隐藏，键盘可操作应用内的按钮。 |
| 安装与 SSH | 15 个账户、安装和启动状态在 4 种窗口及字号组合下通过。SSH 添加、编辑、指纹、部署进度、重试、停止和移除覆盖窄窗与长内容。隔离配置下的真实客户端服务通过主机增删改、重启读回和连接失败检查。 |
| 详情与工作台 | 初始化、工作台与虚拟 Mac 向导直接进入同一终端视图。验证滚动跟随、返回旧行、选取、复制和错误提示。另查 76 个页面状态与 70 处控件区域的布局。 |
| 文案 | 逐项检查桌面、手机网页和移动端原生连接界面中的可见文本，以及三端原生文件窗口。删除设置、SSH 和项目空状态的重复引导。额度缓存说明改为「显示上次查询的额度」，保存或上传中断时提示先核对结果。权限说明保留授权对象，确认操作保留影响范围及恢复方法。 |
| 构建 | 166 项前端单测、ESLint、正式前端构建及 55 项资源完整性检查通过。真实 Windows 外壳与嵌入新资源的 Go 后端在隔离配置下完成 WebView2 原生桥接和退出检查。 |

远程主机的成功部署、客机安装与系统登录使用模拟数据验收。手机网页已跑通交互，Android 和 iOS 原生文案仅做源码核查。在 Windows 直接运行全仓 Go 测试仍有失败，包括找不到 POSIX shell、虚拟机相关用例超时与旧手机会话用例返回 403。旧会话的 403 在未修改的分支基线上也能复现，同一用例以及手机配对和 macOS 项目用例在 WSL 通过。
